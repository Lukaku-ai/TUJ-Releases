# PIX — Poco Instruments & eXtensions

필요할 때 꺼내 쓰는 Windows 도구 모음입니다. PC 정보, 빠른 원격접속(RDP/OpenSSH/PuTTY), 파일 검색, 파일 점유 추적을 제공합니다.

## 설치 및 업데이트

[최신 릴리스](https://github.com/Lukaku-ai/TUJ-Releases/releases/latest)에서 `PIX_Installer_0.0.4.exe`를 실행하고 소유자에게 전달받은 `.tujlic` 라이선스를 선택하세요.

0.0.4은 기존 TUJ 설치 폴더와 AppData의 설정·프로필·색인·캐시를 PIX로 이전합니다. 기존 0.0.1/0.0.2 사용자는 Main부터 업데이트하세요. 선택한 모듈도 0.0.4 이상으로 갱신됩니다. 이전 중 충돌하는 파일을 덮어쓰지 않으며 실행 중인 구버전 모듈은 먼저 종료해야 합니다. 직접 지정한 다른 설치 폴더 이름은 유지합니다.

빠른 원격접속 카드는 별칭·주소·연결 버튼만 표시합니다. 정보·수정·삭제는 카드 우클릭 메뉴에서 사용할 수 있습니다.

모듈에 .NET/WPF 런타임이 포함되어 별도 .NET 설치가 필요하지 않습니다. OpenSSH/PuTTY 접속은 해당 클라이언트가 PC에 있어야 합니다.

초기화 이후 발급한 0.0.1 라이선스와 프로필은 계속 사용할 수 있습니다. 2026-09-11 초기화 이전 설치 파일과 라이선스는 사용할 수 없으며 초기화 이전 버전은 제거 후 새로 설치해야 합니다.

이 저장소에는 공개 설치 및 모듈 배포 파일만 제공합니다. 소스, 라이선스 발급기, 개인키는 포함하지 않습니다. 기존 업데이트 호환을 위해 저장소 주소와 `TUJ_Setup.exe` 다운로드 별칭은 유지합니다.
0.0.4에서는 설치 폴더 이전 중 작업 폴더 잠금, 실패 창으로 인해 업데이트 상태가 계속 남는 문제, 관리자 권한 작업자 인계와 내장 모듈 종료 대기를 보강했습니다. 메인과 모듈 실행 파일 이름도 PIX로 변경했습니다.

이미 업데이트가 멈춘 PC에서는 기존 업데이트 오류 창/작업자를 종료한 뒤 최신 PIX 설치기로 복구 설치하세요. 기존 프로그램을 제거하거나 프로필·라이선스를 삭제할 필요가 없습니다. 업데이트 진단은 `%TEMP%\PIX\Updates\main-update.log`에서 확인할 수 있습니다.
