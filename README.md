# PIX — Poco Instruments & eXtensions

필요할 때 꺼내 쓰는 Windows 도구 모음입니다. PC 정보, 빠른 원격접속(RDP/OpenSSH/PuTTY), 파일 검색, 파일 점유 추적을 제공합니다.

## 설치

[최신 설치 파일과 릴리스](https://github.com/Lukaku-ai/TUJ-Releases/releases/latest)에서 `PIX_Installer_0.0.2.exe`를 실행하고, 소유자에게 전달받은 `.tujlic` 라이선스를 선택하세요.

0.0.2부터 세 모듈에 .NET/WPF 런타임이 포함되어 별도 .NET 설치가 필요하지 않습니다. OpenSSH/PuTTY 접속은 해당 클라이언트가 PC에 있어야 합니다.

초기화 이후 TUJ 0.0.1 사용자는 기존 라이선스와 프로필을 유지한 채 업데이트할 수 있습니다. Main과 모듈을 모두 업데이트하세요. Windows 바로가기 이름까지 PIX로 바꾸려면 새 설치기를 실행하세요.

2026-09-11 초기화 이전 설치 파일과 라이선스는 사용할 수 없습니다. 초기화 이전 버전은 제거 후 새로 설치해야 합니다.

이 저장소에는 공개 설치 및 모듈 배포 파일만 제공합니다. 소스, 라이선스 발급기, 개인키는 포함하지 않습니다. 기존 업데이트 호환을 위해 저장소 주소와 `TUJ_Setup.exe` 다운로드 별칭은 유지합니다.
