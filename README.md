# TUJ — Toolbox for Useful Jobs

Windows용 PC 정보, 빠른 원격접속, 파일 검색, 파일 점유 추적 도구입니다.

## 설치

[최신 설치 파일과 릴리스](https://github.com/Lukaku-ai/TUJ-Releases/releases/latest)에서 `TUJ_Installer_0.0.1.exe`를 실행하고, 소유자에게 전달받은 새 `.tujlic` 라이선스를 선택하세요.

이 저장소에는 공개 설치 및 모듈 배포 파일만 제공합니다. 소스, 라이선스 발급기, 개인키는 포함하지 않습니다.
